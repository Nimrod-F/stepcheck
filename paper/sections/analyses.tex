\section{Static Analyses}
\label{sec:analyses}

\tool{} runs eight independent passes over the IR, each emitting diagnostics with a
stable code (Table~\ref{tab:codes}), a severity, the offending state, and a remediation
note. All are linear in the number of states (the data-flow pass, linear modulo the
control-flow fixpoint) and recurse into nested \texttt{Map}/\texttt{Parallel}
sub-machines.

\paragraph{Structural validation (\code{SC0xxx}).}
A reachability traversal from \texttt{StartAt} (following normal \emph{and} error
transitions) checks that all transition targets exist, that no state is unreachable, that
every non-terminal offers a continuation, that a terminal is reachable, that
\texttt{Choice} states declare a \texttt{Default}, and that \texttt{Map}/\texttt{Parallel}
states are well-formed---sound checks that catch defects AWS reports only at run time.

\paragraph{Data-flow provenance (\code{SC1xxx}, \code{SC1101}).}
This is the analysis of Section~\ref{sec:approach:dataflow}, run as a forward abstract
interpretation that computes each state's document shape and checks the data references
a state evaluates against it (its \texttt{Parameters}/\texttt{ItemSelector} `.\$'
constructors and \texttt{ItemsPath}). A reference to a path that is \emph{definitely
absent} in the state's shape is \code{SC1101}---a sound finding (no false positives). Three legacy
\asl-binding checks are special cases the same pass still reports: a
\texttt{waitForTaskToken} task must pass \texttt{\$\$.Task.Token} (\code{SC1001}); the
\texttt{\$\$.Map} context is valid only inside a \texttt{Map} (\code{SC1002}); and every
payload must be a valid path or \texttt{States.*} intrinsic (\code{SC1003}). \code{SC1101}
goes strictly beyond all of these and beyond what \texttt{statelint}/%
\texttt{asl-validator} check: it is the only one that asks whether the field a
\emph{valid} path names can ever have been produced. With a declared input schema the
shape is closed and the analysis recovers the full \texttt{amount}/\texttt{total} class
(Section~\ref{sec:bg:defects}); \tool{} additionally retains an adjacent-task
field-subset check (\code{SC1010}) as a cheap complement when only per-task schemas, not
a workflow input schema, are declared.

\paragraph{Typestate (\code{SC2xxx}).}
Using \texttt{state\_in}/\texttt{state\_out} labels, the pass checks that adjacent tasks
compose (predecessor output state $=$ successor input state, \code{SC2001}), catching
re-orderings such as ship-before-pay, and that each task's transition is a permitted
protocol edge when one is declared (\code{SC2002}). Absent annotations it is a no-op.

\paragraph{Retry safety (\code{SC3xxx}).}
A task with a \texttt{Retry} policy whose \texttt{ErrorEquals} includes a broad class
(\texttt{States.ALL}/\texttt{States.TaskFailed}) is flagged \code{SC3001} if its
idempotency resolves to \emph{non-idempotent}. Retries restricted to transient errors
(throttling, \texttt{ServiceException}) are not flagged, as they fire before any effect.

\paragraph{Compensation completeness (\code{SC4xxx}).}
A \emph{persistent} task needs either a declared compensation or a \texttt{Catch} path;
one with neither leaves its effect uncompensated (\code{SC4001}), and a compensation
naming a non-existent state is \code{SC4002}.

\paragraph{Concurrency interference (\code{SC5xxx}).}
\texttt{Parallel} branches and \texttt{Map} iterations each receive their own copy of
the state document, so the document cannot race---but the \emph{external} resources
their tasks touch can. The pass mines each task's resource (its integration service plus
the named target: \texttt{TableName}, \texttt{QueueUrl}, \texttt{TopicArn},
\texttt{Bucket}) and, to avoid false positives on idiomatic keyed/commuting patterns,
considers only \emph{overwriting} writes---\texttt{PutItem}/\texttt{PutObject}, which are
last-writer-wins. It excludes \texttt{UpdateItem} (an atomic merge that commutes for
disjoint attributes) and fire-and-forget \texttt{Publish}/\texttt{SendMessage}
(independent messages). It then flags two patterns: two \texttt{Parallel} branches that
both overwrite the \emph{same} resource (\code{SC5001}); and a concurrent \texttt{Map}
(\texttt{MaxConcurrency}~$\neq 1$) whose iterations overwrite a shared resource while
threading \emph{no} per-item data (no `.\$' reference in the write, so every iteration
clobbers the same item, \code{SC5002}). Both are \emph{warnings}, consistent with the
tool's confidence model. No prior \asl{} tool reasons about cross-branch interference.

\paragraph{Retry / timeout budget (\code{SC6xxx}).}
\asl{}'s resilience knobs interact in ways the platform never cross-checks. A
\texttt{waitForTaskToken} (or Activity) task with neither \texttt{TimeoutSeconds} nor
\texttt{HeartbeatSeconds} waits up to a year for a token that may never arrive
(\code{SC6001}, the most common in-the-wild finding---human-approval and external-%
callback steps). When the state machine declares a \texttt{TimeoutSeconds}, the pass
computes a task's worst-case retry budget as the geometric back-off sum
$\sum_k \mathit{interval}\cdot\mathit{backoff}^{\,k}$ and flags retries that cannot
complete within it (\code{SC6002}). Finally \texttt{HeartbeatSeconds}~$\geq$~%
\texttt{TimeoutSeconds} is a definite mis-configuration the platform rejects only at
deploy time (\code{SC6003}).

\paragraph{Worked example.}
\tool{} reports no findings on the well-formed order workflow. Reordering it to ship
before charging (Section~\ref{sec:bg:defects}) yields five errors and no false
positives: two \code{SC2001} typestate mismatches (e.g.\ \texttt{ShipOrder} consumes
\emph{OrderPaid} but its new predecessor produced \emph{OrderReserved}) and three
\code{SC1010} contract mismatches (\texttt{paymentId}, \texttt{amount},
\texttt{reservationId} required but not produced upstream)---complementary checks:
typestate explains the ordering fault, the contract check pinpoints the broken data.
The native data-flow tier needs no annotations at all: on a workflow that constructs
\texttt{\{order:\{orderId,amount\}\}} in a \texttt{Pass} and then reads
\texttt{\$.order.total}, \tool{} reports \code{SC1101} directly---the
\texttt{amount}/\texttt{total} bug caught on raw \asl{}, which \texttt{statelint}
accepts as a valid path.
