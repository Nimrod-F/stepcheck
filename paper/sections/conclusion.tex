\section{Conclusion}
\label{sec:concl}

\tool{} shows that useful static verification can run directly on the AWS Step Functions artifact
developers already deploy. Its native data-flow analysis reports only definite missing-field
failures. Its layered annotations make retry, typestate, and Saga checks precise relative to
supplied facts. On real workflows it rediscovers independently fixed bugs, detects targeted semantic
mutants missed by existing validators, and runs fast enough for CI.

The sound core and the higher-stakes semantic checks sit in different tiers by design. Missing-field
faults are caught with certainty on the raw artifact; the rediscovered and in-the-wild
\code{SC1101} bugs show how they escape testing behind \texttt{Choice} branches. Retry, race, and
compensation faults instead begin as provenance-graded warnings and harden into declared-tier errors
as effects are annotated or inferred. The layering is a migration path, not a fixed line. Serverless
orchestration need not wait until execution to expose data, ordering, retry, timing, and
compensation mistakes.
