\section{Conclusion}
\label{sec:concl}

\tool{} shows that useful static verification can run directly on the workflow artifacts developers
already deploy: raw \asl{}, generated templates, and cross-format definitions. Its native data-flow
analysis reports only definite missing-field failures---free of false positives relative to the modeled I/O semantics, with every error report machine-certified against that model---while layered annotations turn retry,
typestate, and Saga assumptions into provenance-graded diagnostics. The central lesson from the
evaluation is quantitative: classical workflow-net soundness misclassifies 8–29\% of valid workflows—a definitional mismatch with Asl's multi-terminal model—while its vocabulary omits the production bug classes---data flow, retry, concurrency, and
temporal---that \tool{} catches at the artifact level, cheaply enough for a build gate.
Serverless orchestration need not wait until execution to expose data,
ordering, retry, timing, and compensation mistakes, provided the
verifier makes explicit which facts are native, declared, or inferred.

scripts, and reproduction instructions---plus a companion technical report
with the full formal development is at
\url{https://anonymous.4open.science/r/StepCheck}~\cite{stepcheck-repo}.
