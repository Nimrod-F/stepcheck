\section{Background and Problem Setting}
\label{sec:bg}

\asl{} exposes enough structure for native checks, but hides the business facts needed for deeper
workflow verification. This section fixes the small slice of \asl{} semantics used by the
analyses, then states the omitted facts that leave the harder defects latent.
A Step Functions workflow is a state machine with a \texttt{StartAt}
state and named states of eight kinds: \texttt{Task}, \texttt{Choice},
\texttt{Parallel}, \texttt{Map}, \texttt{Wait}, \texttt{Pass},
\texttt{Succeed}, and \texttt{Fail}. A single JSON document is threaded
through the graph, and each state may reshape it through a fixed
five-stage I/O pipeline (\texttt{InputPath} through \texttt{OutputPath})
whose per-stage semantics Section~\ref{sec:approach:dataflow} models
directly.
Reads against the document are explicit in the syntax. A key ending in \texttt{.\$} reads a
JSONPath from the current document (e.g.\ a \texttt{"Payload.\$": "\$.detail.customer"}
constructor reads \texttt{\$.detail.customer}), and the runtime fails the reference when that path
is absent. \asl{} additionally provides workflow variables and JSONata expressions:
\texttt{Assign} stores \texttt{\$var} values for later states, and JSONata fields read
\texttt{\$states.input}, \texttt{\$states.result}, and workflow variables.
Fault handling is likewise explicit: \texttt{Retry} re-executes a state on matching errors,
\texttt{Catch} routes an error to a handler, and \texttt{TimeoutSeconds}/\texttt{HeartbeatSeconds}
bound long-running tasks and callbacks. What the artifact records, an analysis can check; the
question is how far that record reaches.

\label{sec:bg:defects}

The intended protocol in Figure~\ref{fig:intro} is
$\textit{created} \to \textit{reserved} \to \textit{paid} \to
\textit{shipped}$. What \asl{} records already decides three of the six
defects: the missing read~(1) follows from the I/O pipeline alone, and
the racing writes~(4) and unbounded callback~(5) from statically named
resources and absent bounds---natively but conservatively. The other
three depend on facts \asl{} has no syntax for: a task contract
$T : A \to B$, without which reordering~(2) is just another valid edge;
a typestate edge $s^{T}_{\mathit{in}} \to s^{T}_{\mathit{out}}$ in a
business protocol~$\delta$; idempotency of external effects, without
which the double-charging retry~(3) looks safe; and persistence plus a
compensator, without which the uncompensated reservation~(6) looks like
any other task.
Because deployed validators inspect only syntax and structural
well-formedness, all six defects deploy: each is valid JSON over a
valid graph.
