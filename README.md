# Safe Serverless Workflow Orchestration (ICSOC 2026)

This repository contains the paper, the **StepCheck** tool, the evaluation corpus,
the evaluation harness, and the AWS round-trip scripts for the paper *"Safe
Serverless Workflow Orchestration through Typestate Verification, Retry Safety, and
Compensation Checking."*

StepCheck is a static verifier for AWS Step Functions / Amazon States Language (ASL)
workflows. It checks four properties — **data-contract compatibility**, **typestate
(business-protocol) conformance**, **retry safety** (idempotency), and **Saga
compensation completeness** — before deployment, and compiles verified workflows
back to executable ASL. Because raw ASL omits the needed semantics, StepCheck pairs
sound *native* checks with a lightweight *annotation* layer whose defaults are
*inferred* from task names and resource bindings.

## Layout

| Path | What |

## Build & run the tool

```bash
cd stepcheck && cargo build --release
BIN=target/release/stepcheck

# verify a real workflow (with inference)
$BIN check ../corpus/asl/<wf>.asl.json --infer

# the typed-DSL worked example (valid vs reordered)
$BIN demo order      | $BIN check /dev/stdin --annot ../corpus/dsl/order.sidecar.toml
$BIN demo order-bad  | $BIN check /dev/stdin --annot ../corpus/dsl/order.sidecar.toml   # 5 errors

# reproduce the evaluation
$BIN stats ../corpus/asl                 # E1 corpus characterization
$BIN eval  ../corpus/asl --infer         # E2 in-the-wild + E3 mutation study + E5 timing
node ../eval/inference_accuracy.js       # E4 inference accuracy vs gold
```

## Headline results (all reproducible)

- **193** real workflows analysed; **86** flagged in the wild (sound native + inferred-warning tiers).
- Mutation study: **429** injected defects, **100%** detection (delta over baseline).
- Inference accuracy vs gold: **82.9%** idempotency, **91.4%** persistence (≈80% coverage).
- Verification cost: **18.7 µs**/workflow mean; whole corpus in **3.6 ms**; **0** runtime overhead.
- AWS round-trip: a verified workflow deployed and executed on real Step Functions →
  `SUCCEEDED` (then torn down).

## Reproduce the AWS round-trip (optional; creates & deletes resources)

```bash
bash infra/deploy_run.sh   # deploy a verified workflow, run it, capture evidence
bash infra/teardown.sh     # delete the created state machine + lambda
```
